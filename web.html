NURAI 2026 Competition — Team Phoenix — Agriculture Track

What is this system?

Phoenix is an autonomous plant care robot that monitors soil moisture, ambient light, and temperature in real time and uses fuzzy logic to decide when and how much to water each plant — without fixed thresholds or manual intervention.

How fuzzy logic works here

Unlike a simple "if moisture below X, water" rule, fuzzy logic maps sensor readings to membership degrees (low, medium, high) and combines them to produce a nuanced output — the pump duty cycle. This means the system responds proportionally, not just on/off.

Decision rules

IF moisture LOWAND temp HIGH → pump duty HIGH (urgent watering needed)
IF moisture LOWAND temp MEDIUM → pump duty MEDIUM
IF moisture OK→ pump OFF (maintain current state)
IF moisture HIGH→ pump OFF (prevent overwatering)
IF light HIGH→ boost duty (high evaporation expected)
